# Fingerprint Based Non-Invasive Blood Group Detection Using Deep Neural Nets

This repository contains the implementation of our research work on **non-invasive blood group detection using fingerprint images and deep neural networks**.

The work explores the use of fingerprint patterns as a biometric input for predicting human blood groups using deep learning-based image classification.
